# Testing

Use `pnpm run lint`, `pnpm run typecheck`, `pnpm exec vitest ...`, `pnpm exec playwright test ...`, and `pnpm exec prettier --check ...` based on the changed files. Tests live under `tests/server/**`, `tests/components/**`, `tests/guest/**`, `tests/reserve/**`, `tests/e2e/**`, `tests/cloudflare/**`, and `tests/a11y/**`.

Related: [Tooling](tooling.md).
