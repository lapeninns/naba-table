# Data models

Supabase migrations under `supabase/migrations/**` define database shape; this snapshot found 54 SQL migration files. Important model areas include bookings (`server/bookings.ts`), restaurants (`server/restaurants/**`), capacity (`server/capacity/**`), delivery (`server/emails/**`, `server/sms/**`), and dual sync (`server/dual-sync/**`).
