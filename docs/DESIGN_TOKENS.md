# Design Tokens Reference

> **Radix Luma — Nabatable design tokens**
>
> Quick reference for the token layer. Every value here is read from the two source files
> below; if a token is missing from those files it does not exist, whatever an older note says.

> [!NOTE]
> **Sources of truth**
>
> - **`styles/design-system/public-guest.tokens.css`** — every `--pg-*`, semantic shadcn
>   (`--background`, `--primary`, …), radius, shadow, motion, density and layout token, plus the
>   `[data-theme='app']` and `.dark` overrides.
> - **`src/app/globals.css`** — the Tailwind v4 `@theme inline` mapping that turns those tokens into
>   utilities (`bg-primary`, `rounded-xl`, `tracking-display`, …).

>   drifts.
> - Brand values: **`GUEST_FACING_DESIGN_SYSTEM.md`**. Decisions: **`docs/design/luma-2.0-spec.md`**.
>   Ops-surface contract: **`DESIGN.md`**.

## Surfaces and theming

Two surfaces share one token set. Tokens are defined on `:root`, so components render fully styled
with no wrapper; the surface attribute only switches the per-surface overrides.

| Selector                       | Surface                | What changes                                                                              |
| :----------------------------- | :--------------------- | :---------------------------------------------------------------------------------------- |
| `:root` / `[data-theme=guest]` | Guest, marketing, auth | Defaults: Merriweather display face, comfortable density                                  |
| `[data-theme=app]`             | Ops console            | `--pg-font-display` → Inter (all-sans), compact `--pg-density-*`                          |
| `.dark` (orthogonal)           | Either surface         | Full re-tuned palette (not an inversion), translucent white borders, deeper shadow alphas |

Light mode is the default on first load; the toggle persists to `localStorage`. `.guest-theme` is a
compatibility class equivalent to `[data-theme=guest]` and is tracked as review debt by `guard:luma`.

Zinc neutrals with one accent: cobalt `#1447E6`. The accent is for interactive affordance only —
CTAs, links, active states, focus rings, key numbers — never decoration.

## Typography

Merriweather for display and headline tiers (guest only; ops resolves the display face to Inter),
Inter for everything else, Geist Mono for code and technical values. Four weights only: 400 body,
500 labels, 600 buttons/eyebrows, 700 headlines.

| Font token          | Value                                               |
| :------------------ | :-------------------------------------------------- |
| `--pg-font-display` | Merriweather (`--font-radix-luma-display`), Georgia |
| `--pg-font-body`    | Inter (`--font-radix-luma-body`), system sans       |
| `--pg-font-mono`    | Geist Mono (`--font-radix-luma-mono`), ui-monospace |

### Scale

Display and headline tiers are **fluid** (`clamp()`), body and below are **fixed**; body text never
scales. Tracking is inversely proportional to size.

| Tier            | Size token             | Value                                | Leading token                 | Weight    | Tracking                        | Primitive                                             |
| :-------------- | :--------------------- | :----------------------------------- | :---------------------------- | :-------- | :------------------------------ | :---------------------------------------------------- |
| Display         | `--pg-text-hero`       | `clamp(2rem, 5vw, 3rem)` 32→48       | `--pg-leading-tight` 1.1667   | 700       | `--pg-tracking-display` −0.02em | `<Heading variant="display">`                         |
| Headline-lg     | `--pg-text-section`    | `clamp(1.75rem, 4vw, 2.25rem)` 28→36 | `--pg-leading-snug` 1.2222    | 700       | `--pg-tracking-tight` −0.01em   | `<Heading variant="section">`                         |
| Headline-md     | `--pg-text-card-title` | `clamp(1.25rem, 3vw, 1.5rem)` 20→24  | `--pg-leading-heading` 1.3333 | 700       | 0                               | `<Heading variant="card">`                            |
| Title-lg (sans) | `--pg-text-title`      | 1.25rem / 20px                       | `--pg-leading-title` 1.4      | 600       | 0                               | `<Heading variant="title">`                           |
| Body-lg         | `--pg-text-lead`       | 1.125rem / 18px                      | `--pg-leading-lead` 1.5556    | 400       | 0                               | `<Text variant="lead">`                               |
| Body-md         | `--pg-text-body`       | 1rem / 16px                          | `--pg-leading-body` 1.5       | 400       | 0                               | `<Text variant="body">`                               |
| Body-sm / label | `--pg-text-caption`    | 0.875rem / 14px                      | `--pg-leading-compact` 1.4286 | 400 / 500 | 0                               | `<Text variant="caption" \| "label" \| "subheading">` |
| Button          | `--pg-text-caption`    | 14px                                 | `--pg-leading-compact`        | 600       | `--pg-tracking-button` +0.01em  | `<Button>`                                            |
| Eyebrow         | `--pg-text-kicker`     | 0.75rem / 12px, uppercase            | `--pg-leading-heading`        | 600       | `--pg-tracking-wide` +0.08em    | `<Text variant="eyebrow">`                            |

`tracking-eyebrow`, `tracking-button`. Prefer the `<Heading>` / `<Text>` primitives in
`components/ui/typography.tsx` over raw `text-2xl…` utilities — `guard:typography-scale` ratchets
the raw count downward.

Restrained identity (Luma 2.0 §4.5). The same steps are defined in both source files and must stay

## Elevation

Depth comes from tonal layering and 1px borders, not heavy shadows. Level 1 (cards) has **no resting
shadow**; only interactive cards lift to `shadow-md` on hover. Level 2 (popovers) uses
`--pg-shadow-popover`. All shadows are Zinc-950-tinted, never pure black.

| Token                                            | Tailwind    | Light                                                   | Dark alpha |
| :----------------------------------------------- | :---------- | :------------------------------------------------------ | :--------- |
| `--shadow-sm` / `--pg-shadow-xs`                 | `shadow-sm` | `0 1px 2px rgb(9 9 11 / 0.05)`                          | 0.24       |
| `--shadow` / `--pg-shadow-sm`                    | `shadow`    | `0 1px 3px … / 0.1, 0 1px 2px … / 0.06`                 | 0.28       |
| `--shadow-md` / `--pg-shadow-md`                 | `shadow-md` | `0 4px 6px -1px … / 0.1, 0 2px 4px -2px … / 0.1`        | 0.30       |
| `--shadow-lg` / `--pg-shadow-lg`                 | `shadow-lg` | `0 10px 15px -3px … / 0.1, 0 4px 6px -4px … / 0.1`      | 0.35       |
| `--shadow-xl`                                    | `shadow-xl` | `0 20px 25px -5px … / 0.1, 0 8px 10px -6px … / 0.1`     | 0.35       |
| `--pg-shadow-nav`                                | —           | `0 8px 30px rgb(9 9 11 / 0.04)` — floating navbar       | 0.24       |
| `--pg-shadow-button`                             | —           | `0 10px 15px -3px rgb(20 71 230 / 0.15)` — cobalt glow  | 0.18       |
| `--pg-shadow-popover`                            | —           | `0 10px 38px -10px … / 0.35, 0 10px 20px -15px … / 0.2` | same       |
| `--pg-shadow-edge`                               | —           | `inset 0 1px 0 rgb(255 255 255 / 0.65)`                 | 0.08       |
| `--pg-shadow-soft` / `--pg-shadow-floating`      | —           | → `--pg-shadow-sm` / `--pg-shadow-popover`              |            |
| `--shadow-card` / `-hover` / `--shadow-featured` | —           | → sm / md / md                                          |            |

Materials: floating nav = background at 80% with `backdrop-blur-xl`; popovers = 90% with 16px blur.

## Motion

Brief, precise, purposeful. Reduced motion is neutralised globally in `globals.css`.

| Token                                    | Value                               | Use                                                 |
| :--------------------------------------- | :---------------------------------- | :-------------------------------------------------- |
| `--pg-duration-fast` / `--duration-fast` | 150ms                               | Hover, focus, colour                                |
| `--pg-duration` / `--duration-normal`    | 250ms                               | Dropdowns, accordions, tabs                         |
| `--pg-duration-slow` / `--duration-slow` | 500ms                               | Sidebar, panel resize                               |
| `--pg-duration-reveal`                   | 800ms                               | Scroll-triggered entrances (stagger children 100ms) |
| `--pg-ease-out`                          | `cubic-bezier(0.25, 0.1, 0.25, 1)`  | Default — invisible micro-interactions              |
| `--pg-ease-spring`                       | `cubic-bezier(0.22, 1, 0.36, 1)`    | Signature — reveals, page transitions               |
| `--pg-ease-snap`                         | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Bounce — toasts, badge counts, sparingly            |
| `--pg-transition-hover`                  | fast + ease-out                     | Affordance feedback                                 |
| `--pg-transition-panel`                  | normal + spring                     | Surface enter/settle                                |
| `--pg-transition-emphasis`               | slow + spring                       | Deliberate reveal                                   |

Use via arbitrary values: `transition-[var(--pg-transition-panel)]`, `ease-[var(--pg-ease-spring)]`.
Interaction feedback: buttons press (`active:scale-[0.98] active:translate-y-px`), interactive cards
lift, focus shows a 3px ring at 30%.
