Design system · light and dark · guest and app

Radix Luma

Zinc neutrals with one cobalt accent. Switch surfaces above: Guest uses Merriweather headings and capsule buttons. App is the ops console, with Inter throughout, 14px body text and 8px controls. Press d to switch between light and dark.

Solid success (#16a34a), warning (#f59e0b) and info (#0ea5e9) fail with small white text (3.3, 2.1 and 2.9:1). Use them only for icons, and use the tint and deep-text pairs for labels.

Typography

Merriweather 700 for guest headings, Inter for everything else, and Geist Mono for codes and times. Use no more than two weights on a screen.

Rules
  • Don't recolour, stretch or rotate the mark, and don't add effects to it.
  • Its gradient is its own. Never use logo blues in the UI.
  • Use the animated mark only for hero or loading moments.
  • No clear-space or minimum-size rule has been set yet.

Buttons

Use one filled primary per view. On the guest surface buttons are capsules; in the app they use an 8px radius. Every size keeps a 44px hit area.

Primary hover darkens to #1240cf and adds the cobalt glow. When pressed, it scales to 0.98 and moves down 1px. Hover the primary above to try it. Text never gets lighter on hover.

Forms

Labels go above the input and never float. Errors appear below the field with an icon, and focus uses the ring halo with a cobalt edge.
