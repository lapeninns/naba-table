Reference material for AI coding agents working in this repo. The root `/AGENTS.md` contains binding policy; these docs provide detail.

| Document                               | Purpose                                                      |
| -------------------------------------- | ------------------------------------------------------------ |
| [sdlc.md](sdlc.md)                     | SDLC phases, task folder templates, Definition of Ready/Done |
| [task-structure.md](task-structure.md) | Task folder naming, required files, frontmatter              |
| [ui-standards.md](ui-standards.md)     | Frontend component, accessibility, and UX standards          |
| [db-migrations.md](db-migrations.md)   | Supabase migration procedures and safety checklist           |
| [tooling.md](tooling.md)               | MCP tooling catalog and usage by phase                       |

## Precedence

- Root `/AGENTS.md` is binding policy — always follow it.
- These docs expand on root policy with procedures and templates.
- Nested `AGENTS.md` files add path-specific constraints (closest wins, except root non-overridables).
