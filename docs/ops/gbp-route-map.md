## Rules For Future Changes

- Prefer canonical `/google-business-profile/**` or `/dual-sync/**` routes for new work.
- Do not add new behavior to legacy `/google-business/**` routes without caller evidence and compatibility justification.
- Do not delete legacy routes until client callers and production traffic are checked.
- Treat source-inferred behavior as source-inferred; record live verification separately.
- Keep direct GBP manual sync and destructive disconnect actions password-confirmed on canonical and legacy routes.
- Use `docs/ops/gbp-production-wiring-checklist.md` before deployed environment wiring.
- Use `docs/sdlc/gbp-dual-sync-extension-guide.md` before adding a syncable field family.

## Protected Action Policy

| Action family             | Route family                                                                         | Current policy                                                                                                                                                              | Rationale                                                                                            |
| ------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Start OAuth               | `/google-business-profile/connect`, `/google-business/connect`                       | Restaurant admin access plus HttpOnly browser state cookie. No password prompt.                                                                                             | Begins an external consent loop but does not itself store credentials or write public data.          |
| OAuth callback            | Global and legacy callback routes                                                    | Matching browser state cookie, signed-in user, service-side state ownership, expiry, and replay checks.                                                                     | Completes a previously initiated OAuth state and stores credentials only after service checks.       |
| Location selection/link   | Canonical `PUT /google-business-profile`; legacy `/google-business/locations/select` | Restaurant admin access, payload validation, discovered-location link, and read-only snapshot sync. No password prompt.                                                     | Links a discovered GBP listing and refreshes local comparison data; it is not a public Google write. |
| Manual business-info sync | Canonical `POST /google-business-profile`; legacy `/google-business/sync`            | Restaurant admin access, password confirmation, provider refresh budget, then read-only Google pull.                                                                        | Explicit operator-initiated provider sync should require a fresh local-auth confirmation.            |
| Disconnect                | Canonical `DELETE /google-business-profile`; legacy `DELETE /google-business`        | Restaurant admin access, password confirmation, then connection unlink.                                                                                                     | Destructive local credential/profile unlink must not be reachable through a legacy bypass.           |
| Dual-sync publish preview | `/dual-sync/publish/preview`                                                         | Restaurant admin access, pinned decisions, capability/policy validation, read-only plan. No password prompt.                                                                | Preview does not mutate Core or Google.                                                              |
| Dual-sync publish         | `/dual-sync/publish`                                                                 | Restaurant admin access, pinned hashes, runtime flags, pause/lock checks, capability/policy gates, edit budget, audit, and operator confirmation. No route password prompt. | Public-write risk is controlled by the dual-sync safety contract rather than password confirmation.  |
