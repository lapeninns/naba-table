This review is source-backed. It does not claim production scheduler installation, live Google behavior, or remote Supabase verification.

## Scope

- Canonical GBP routes under `/api/ops/restaurants/:id/google-business-profile/**`.

- Dual-sync state, preview, publish, queue, pause, cron, request-log, and FoodMenus paths.
- Shipped settings route `/settings/restaurant/google-business-profile`.

## FoodMenus Safety Contract

- FoodMenus lives in the dual-sync registry and can be represented in preview/publish decisions as `sectionKey: foodMenus`.
- Google FoodMenus writes are full-resource replacements and must use `updateMask=menus`.
- Provider `validateOnly` is not available for the FoodMenus endpoint; source marks the group as `preflightUnsupported: true`.
- `preflightUnsupported` is not approval to skip review. The path still needs fresh pinned hashes, baseline/projection checks, high-risk confirmation, edit-budget enforcement, and audit.
- The default export preflight currently fails FoodMenus replacement unless the alternate baseline contract is explicitly satisfied by the implementation path being tested.

## Production Non-Claims

- No live Google write was performed for this review.
- No production/staging Supabase schema readback was performed for this review.
- No Vercel environment values or deployed cron scheduler installation were verified for this review.
- Production readiness requires the checklist in `docs/ops/gbp-production-wiring-checklist.md`.
