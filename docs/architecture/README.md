# Architecture Documentation

This directory contains architecture diagrams and service flow documentation for the Nab a Table platform.

## Contents

- [System Overview](./system-overview.mermaid) - High-level system architecture
- [Booking Flow](./booking-flow.mermaid) - Guest booking journey sequence
- [Data Flow](./data-flow.mermaid) - Data flow between components

## Viewing Diagrams

These diagrams use [Mermaid](https://mermaid.js.org/) syntax and can be viewed:

- Directly on GitHub (renders automatically)
- In VS Code with the "Markdown Preview Mermaid Support" extension
- At [mermaid.live](https://mermaid.live) for interactive editing
