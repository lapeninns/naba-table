# Tech Debt Ledger

Use this ledger to track technical debt items and link each entry to a GitHub issue created from the Tech Debt issue template.

## Status Definitions

- **Proposed**: Identified but not yet scheduled.
- **Planned**: Scheduled for upcoming work.
- **In Progress**: Actively being addressed.
- **Mitigated**: Resolved or reduced to an acceptable level.
- **Dropped**: No longer relevant; document rationale in Notes.
